# Daily Email Priority Assistant (AI)

## What it does
An AI-powered workflow that runs every morning before work
to highlight important emails that require action or awareness.

## Workflow Steps
- Triggers daily at 8 AM
- Fetches recent inbox emails
- Cleans and structures email content
- Uses an AI agent to understand intent and urgency
- Filters out low-priority noise
- Stores important summaries in Notion

## Why it matters
This workflow helps reduce cognitive overload and ensures
important tasks or decisions are not missed.

## Built With
- n8n
- Groq LLM
- Gmail API
- Notion API
