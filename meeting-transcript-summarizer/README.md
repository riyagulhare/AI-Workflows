# Meeting Transcript to Actionable Summary (AI)

## Overview
An AI-powered workflow that converts raw meeting transcripts into
clear, structured summaries with decisions, action items, owners,
and deadlines.

This ensures alignment across teams and prevents important outcomes
from getting lost after meetings.

## What Problem It Solves
Meetings generate valuable discussions, but:
- Transcripts are long and unstructured
- Action items are forgotten
- Stakeholders miss key decisions

This workflow transforms conversations into execution-ready outputs.

## Workflow Steps
- Accepts meeting transcripts via form or document input
- Cleans and structures raw text
- Uses an AI agent to extract:
  - Key discussion points
  - Decisions made
  - Action items
  - Owners and deadlines
- Formats the output into a readable structure
- Automatically shares the summary via email or workspace tools

## Why This Matters for Product Teams
- Improves cross-functional alignment
- Ensures accountability
- Reduces follow-ups and confusion
- Speeds up execution after meetings

## Built With
- n8n
- LLM (Groq / OpenAI)
- Email / Notion / Workspace tools

## Example Use Case
After a product strategy meeting, automatically send a concise summary
with clear next steps to all stakeholders.
